Enterprise Security. Tiny Footprint.

A professional security kit crafted specifically for solo devs, side projects, and micro-teams.

AES-256-GCM Encryption

Encrypt files at rest using authenticated cryptography. Rest assured that your keys can never be modified or read without your master password.

Zero-Disk Runtime Injection

Decrypt secrets directly into your application process memory at boot time. Plaintext secrets never touch the disk, protecting against physical theft.

Git-Guard Pre-Commit Protection

Install our automated Git pre-commit hook in one click. Blocks attempts to commit plaintext credentials, preventing embarrassing leaks.

Quickstart in 30 Seconds

Zero configuration, zero overhead. Copy and run right away.

1. Installation 2. Encrypt Secrets 3. Run Injector 4. Install Git Guard

1. Installation

Install the package globally on your machine, or run it dynamically with npx:

npm install -g env-secret-lock

2. Encrypt Secrets

Convert your plaintext .env file into a highly secure .env.enc file using AES-256-GCM:

secret-lock encrypt

You will be prompted to enter and confirm your master password securely. Afterwards, add your plaintext .env file to .gitignore.

3. Run Injector

Launch your project with secrets decrypted directly into memory. They will reside only in process memory without hitting the disk:

secret-lock run "node index.js"

💡 CI/CD Tip: In non-interactive environments, export SECRET_LOCK_PASSWORD=yourpass to run without interactive prompts.

4. Install Git Guard

Add a lightweight pre-commit hook to automatically intercept git commits that contain raw, plaintext env files:

secret-lock hook install

To remove the hook at any time, run secret-lock hook uninstall.
