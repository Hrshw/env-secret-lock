# Security Policy

## Supported Versions

We actively monitor and patch security vulnerabilities. Please use the latest release of `env-secret-lock`.

| Version | Supported          |
| ------- | ------------------ |
| v1.0.x  | :white_check_mark: |
| < v1.0  | :x:                |

## Reporting a Vulnerability

Because `env-secret-lock` is a security-focused tool designed to encrypt developer environment variables, we take security extremely seriously. 

If you discover a security vulnerability, **please do not open a public issue.** Publicly disclosing a security flaw allows anyone to exploit it before we have a chance to release a patch.

Instead, please report security issues privately:

1. Send an email to **rahulsinghpilani7@gmail.com** with the subject: `[SECURITY VULNERABILITY] env-secret-lock`.
2. Provide a detailed description of the vulnerability, including step-by-step instructions to reproduce it (a Proof of Concept).
3. We will acknowledge your email within 24–48 hours, work on a patch, and coordinate a secure release date.

Thank you for helping keep our developer community safe!
